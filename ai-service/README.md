# IATERAP AI Advisory Service

FastAPI microservice, architecturally independent from the Spring Boot
backend (`../backend`). This is a **skeleton** — no real AI inference, no
Coverage Engine, no external model calls.

## Endpoints

| Method | Path                                    | Purpose                                               |
|--------|------------------------------------------|--------------------------------------------------------|
| GET    | `/health`                                | Health check                                            |
| POST   | `/suggest`                               | AI-165: deterministic canned advisory response          |
| POST   | `/advisory/recommendations`              | AI-242: explainable fault/test recommendations          |
| GET    | `/context/test-procedure/{id}`           | AI-175/AI-234: read-only, versioned procedure and coverage-gap context |
| GET    | `/docs`                                  | Swagger UI (auto-generated by FastAPI)                  |
| GET    | `/openapi.json`                          | OpenAPI schema                                          |

## Run locally

```bash
cd ai-service
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

Then visit `http://localhost:8000/docs`.

## Run tests

```bash
cd ai-service
pip install -r requirements.txt pytest
pytest -q
```

## Run via Docker Compose

From the repository root:

```bash
docker compose -f docker/docker-compose.yml up --build
```

This starts Postgres (5432), the Spring Boot backend (8080), and this
service (8000).

## Advisory recommendations (AI-242)

`POST /advisory/recommendations` accepts a target LRU and caller-supplied,
read-only historical LRU cohort. It uses pandas to normalize the cohort and
scikit-learn TF-IDF/cosine similarity across LRU name, subsystem, interfaces,
and protocols. It returns the similarly ranked LRUs, fault scenarios absent
from the target's known set, and candidate test cases linked to those faults.

Every returned fault scenario and candidate test case includes a numeric
`confidence` and `confidence_evidence`: the strongest historical similarity,
the count of independently supporting LRUs, a capped corroboration uplift, and
a `LOW`, `MEDIUM`, or `HIGH` confidence band. Confidence is explainable
decision-support evidence, never an automatic safety or approval decision.

The result is deterministic and explainable; it does not call an external LLM,
write to IATERAP, create test procedures, or approve engineering decisions.
Every recommendation remains subject to Test Engineer review and the existing
approval workflow.

Response:
```json
{
  "suggestion": "This is a placeholder suggestion from the IATERAP AI Advisory skeleton service. No inference has been performed.",
  "confidence": 0.0,
  "source": "stub",
  "generated_at": "2026-08-12T05:03:04.426342Z"
}
```

## Example: `/context/test-procedure/{id}` (AI-175 contract)

Response shape is defined in `app/context_models.py`
(`TestProcedureContext`, `TestStepContext`, and `CoverageContext`), versioned
via `contract_version`. Field names mirror the backend's `TestStep` /
`TestProcedure` JPA entities and the Spring read-only boundary
`GET /api/ai/context/test-procedure/{id}`. The example response includes the
same deterministic coverage categories, thresholds, and structured gaps that
the live backend contract exposes. The service performs no database writes.
