# Month 4 Demo: AI Suggestions and Reliability

1. Open **AI Suggestions**, request an advisory draft for a procedure step, then explicitly accept it.
2. Open that procedure in **Procedure Builder**, apply the accepted suggestion, and save. The saved revision retains the engineer attribution in step remarks.
3. Open **Reliability Analytics**, generate synthetic events for an aircraft, then review the persisted monthly report table.
4. Open the Pareto/HFRA dashboard to show ranked contributors, cumulative failure contribution, repeat-failure flags, and the transparent mean-plus-standard-deviation HFRA threshold.

All demonstration evidence is labelled synthetic. AI output is advisory and cannot modify a procedure without engineer acceptance and a normal saved revision.
